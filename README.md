# 🍔 YumFood — Online Food Ordering Platform

YumFood is a full-stack food ordering platform built with **React.js**, **Django**, and **Django REST Framework**. It provides a modern interface for browsing food, managing carts, placing orders, tracking orders, and interacting with restaurants.

## 🚀 Features

* 🔐 JWT authentication
* 👤 User registration and login
* 🍔 Food and menu browsing
* 🔎 Search and filtering
* 🛒 Shopping cart management
* 📦 Order placement and tracking
* ⭐ Reviews and ratings
* 👨‍💼 Admin dashboard
* 💳 Online payment integration
* 📱 Responsive user interface
* 🔗 REST API integration

## 🛠️ Technologies

### Frontend

* React.js

### Backend
